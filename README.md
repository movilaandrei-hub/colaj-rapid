# Boomly

Faci pozele, aplicația face restul: alege singură pozele bune și creează un colaj, un carusel sau un Reel animat cu muzică, gata de salvat sau trimis pe Instagram, Facebook, TikTok sau WhatsApp.

**Aplicația:** https://movilaandrei-hub.github.io/colaj-rapid/

## Instalare pe Android

1. Deschide adresa de mai sus în Chrome.
2. Meniul ⋮ → **Adaugă pe ecranul de pornire** (sau **Instalează aplicația**).
3. Pornește „Boomly” de pe ecranul telefonului.

Pozele rămân pe telefon. Nimic nu se trimite pe internet.

## Pentru dezvoltare

- `colaj-rapid.html` e sursa aplicației.
- `node build-site.js` construiește aplicația instalabilă în `docs/` (de acolo o servește GitHub Pages).
